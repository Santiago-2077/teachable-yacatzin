# Detector PET – Reciclaje Yacatzin

Complemento para la página web Reciclaje Yacatzin. Usa la cámara del dispositivo para detectar si un objeto es una botella PET o no, con dos posibles resultados: **SÍ es PET** o **NO es PET**.

Construido con Teachable Machine, TensorFlow.js y JavaScript vanilla.
